# Website Spec

## Purpose
Showcase services and validate demand. Not a functional product — a sales page.

## Structure
Single scrolling landing page with sections:
1. Hero (headline + value prop + primary CTA)
2. Services (categorized by verb: Build, Create, Market, Support)
3. Pricing (3 tiered packages — e.g. Starter / Growth / Enterprise)
4. Social proof / trust signals (TBD — testimonials, logos, case studies as they come)
5. CTA section (email signup + book a call)
6. Footer

## CTAs
- Email capture (waitlist / newsletter)
- Book a discovery call

## Design direction
- Clean and minimal
- Lots of whitespace, simple typography, understated
- No existing brand assets — name, palette, typography all TBD

## Brand name
**Lux** — Latin for "light." Short, punchy, universally understood. Conveys clarity, intelligence, and simplicity. Domain TBD (checking availability for lux.agency, lux.tools, lux.work, lux.so, withlux.com, getlux.com).
